# ADR-005 — Autenticidade e sincronização de Google Calendar

Estado: proposta de referência da Phase 0, para revisão no PR.

## Contexto

O requisito genérico de assinatura não descreve o mecanismo Google push.

## Decisão

Validar channel token/IDs/expiry; usar evento apenas para disparar fetch autenticado; sync token, renewal e reconciliação.

## Alternativas e consequências

Adaptação explícita de §76; nenhuma HMAC fictícia. Google docs em calendar.md. Notificação não é autoridade sobre booking.

## Validação

P7: token inválido/replay, expiry, 410, paginação, OAuth revogado e conflito.
