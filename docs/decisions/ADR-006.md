# ADR-006 — Sandbox e controlo determinístico da IA

Estado: proposta de referência da Phase 0, para revisão no PR.

## Contexto

Prompt sozinho não isola dados, custos ou efeitos.

## Decisão

Provider abstractions, registry server-side, tools scoped ao customer, repositories sandbox separados, teto de ações/custo e epoch de conversa.

## Alternativas e consequências

Motor partilhado com infraestrutura de persistência/saída diferente no sandbox; maior esforço de testes. Nenhuma tool aceita tenant/ambiente escolhidos pelo LLM.

## Validação

P5/P8: injection, customer IDOR, nenhuma escrita/envio live em sandbox, takeover durante inferência.
