# ADR-004 — Reservas por recurso e exclusão PostgreSQL

Estado: proposta de referência da Phase 0, para revisão no PR.

## Contexto

Staff é opcional e locks efémeros não impedem todas as corridas.

## Decisão

Resource obrigatório default/staff, intervalos ocupados com buffers, transação/lock de resource e GiST exclusion para pending/confirmed.

## Alternativas e consequências

SQL especializado em migrations além do Prisma; multi-capacidade pós-MVP. Edições externas Google não têm atomicidade conjunta.

## Validação

P6: uma reserva numa corrida, default resource, buffers, DST, rollback de remarcação.
