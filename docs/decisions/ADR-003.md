# ADR-003 — Outbox e idempotência durável

Estado: proposta de referência da Phase 0, para revisão no PR.

## Contexto

Commit local e publicação na fila não são transação única.

## Decisão

Outbox transacional, consumer receipt na transação dos efeitos; jobs at-least-once e chaves duráveis de operação. Redis apenas acelera.

## Alternativas e consequências

Custo de dispatcher/limpeza; duplicados de entrega inevitáveis. Providers com resultado ambíguo requerem reconciliação, não promessa exactly-once.

## Validação

P4: crash em cada fronteira, Redis down, duplicados concorrentes, timeout após envio.
